# Слово пацана — Godot 4 port

The same game as `../slovo-patsana` (the three.js prototype), rebuilt in Godot 4.4: the Kazan
district, the fighters and their animations, cars, traffic and militsiya, the three story
missions, the Mortal Kombat-style select with the two customisable bonus fighters, touch
controls, and a Russian / English ("a gentleman's word") text switch.

## Run it

- Install [Godot 4.4.1](https://godotengine.org/download) (the standard build, no C# needed).
- Open this folder (`project.godot`) in Godot and press Play, or from a terminal:
  `godot --path slovo-patsana-godot`.
- Scripted checks without a window: `godot --path . --headless --script tools/testcar.gd`, or a full
  play-through under a virtual display:
  `xvfb-run godot --path . --rendering-driver opengl3 -- --test roam` (tests: `roam`, `drive`, `menu`,
  `menu_en`, `versus`, `story`; screenshots land in `/tmp/sp/`).

## Export

`export_presets.cfg` holds two presets:

- **Web**: single-threaded (runs in iPhone Safari), GL Compatibility renderer, light assets
  (`assets_m/`, 512 px textures). `godot --headless --path . --export-release Web out/web/index.html`.
  The output is served from the `gh-pages` branch under `/g/`.
- **Windows Desktop**: Forward+ renderer, full assets, one `.exe` with the data embedded.
  `godot --headless --path . --export-release Windows out/win/SlovoPatsana.exe`.

Export templates for 4.4.1 must be installed (`Editor → Manage Export Templates`).

## Layout

| Path | What |
|---|---|
| `src/core/` | `Game.gd` (autoload: world, modes, quality, portraits, hit-stop), `BoxGrid`, `FollowCam`, `PlayerInput`, `Assets` |
| `src/actors/` | `Body` (GLB + AnimationTree blend), `Fighter` (combat state machine), `Brain` (AI), `Characters` (roster, bonus save), `Looks`, `Tint` |
| `src/combat/Attacks.gd` | Damage, range, timing and knockback for every move |
| `src/world/` | `City` (district generator), `Facades`, `Trees`, `Env` (sky, fog, moon, lamps, snow), `MeshLib`, `Shaders` |
| `src/vehicles/` | `CarModel` (paint shader, lights), `Vehicle` (arcade dynamics), `Traffic` (AI drivers) |
| `src/game/` | `Boot`, `Menu`, `Select`, `FreeRoam`, `Streets` (cars + militsiya), `Versus`, `Story` |
| `src/ui/` | `Hud` (with minimap), `TouchUI`, `UI` helpers, `T` (RU/EN strings), `Controls`, `Credits` |
| `assets/` | Full models and textures; `assets_m/` the light set for web and phones; `assets/audio` generated by `tools/gen_audio.py` |
| `tools/` | Test scripts and generators |

Credits for the CC-BY models are in `assets/CREDITS.txt` and on the in-game «Авторы» screen.
